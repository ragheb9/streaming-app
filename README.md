# حروفي — تطبيق تعلّم العربية للأطفال

تطبيق ويب أصلي باللغة العربية ومهيّأ للأجهزة اللوحية، بما فيها تابلت Samsung Galaxy. يحتوي على دروس حروف تفاعلية، لعبة مطابقة، قصة مصوّرة، لوحة إنجازات، وواجهة مبسطة للأهل. لا يستخدم علامة Arabee التجارية أو موادها.

## التشغيل

يتطلب Node.js 18 أو أحدث.

```bash
npm install
npm run dev
```

افتح عنوان Vite المحلي في المتصفح. لإنشاء نسخة إنتاج:

```bash
npm run build
npm run preview
```

## المزايا الموجودة

- واجهة عربية RTL متجاوبة، شريط جانبي للتابلت وشريط تنقّل سفلي للهاتف.
- درس تفاعلي من ثلاثة أسئلة مع إجابة فورية وقراءة صوتية عبر Speech Synthesis عند دعم المتصفح.
- لعبة مطابقة كلمات تبدأ بالحرف نفسه.
- قصة قصيرة مصوّرة متعددة الصفحات مع خيار الاستماع.
- نجوم، دروس مكتملة، شارات وسجل محفوظ محلياً في المتصفح.
- واجهة الأهل خلف سؤال حسابي تجريبي، وإمكانية إعادة ضبط التقدم.
- تبديل اللغة في الشريط العلوي (يبدّل اتجاه العرض؛ الترجمة الإنجليزية الكاملة غير مفعّلة بعد).

## حدود النسخة

هذه نسخة ويب أمامية مكتملة كتجربة تعليمية قابلة للتشغيل، لكن لا تتضمن خادماً أو تسجيل دخول/مزامنة بين الأجهزة أو نظام إدارة محتوى. البيانات تحفظ محلياً على الجهاز. بوابة الأهل ليست حماية أمنية حقيقية. الصور والرسوم التوضيحية الحالية رموز تعبيرية، والخطوط تُحمّل من Google Fonts؛ يمكن لاحقاً استبدالها بأصول ورسوم مرخّصة وإضافة backend ومحتوى منهجي معتمد.
